# Оптимизация маршрутной сети общественного транспорта на основе пассажиропотока


Одностраничное аналитическое веб-приложение для пространственного анализа пассажиропотоков, выявления перегруженных пересадочных узлов, оценки непрямолинейности трасс, поиска дублирующих маршрутов и имитационного моделирования интервалов движения наземного общественного транспорта Москвы.

Работает на **реальных открытых данных Правительства Москвы (`data.mos.ru`)**: датасет собирается из официальных реестров остановок, вестибюлей и статистики пассажиропотока метрополитена.

## Возможности

* **Фильтры** — каскадный выбор любого из 12 административных округов Москвы (включая макроанализ всей городской сети) и муниципального района.
* **Пространственный анализ и ТПУ** — KPI-карточки (число остановок, пиковый поток, удалённые узлы > 800 м, среднее расстояние до метро), тепловая карта спроса, маркеры перегруженных узлов и диаграмма зависимости потока от удалённости метро.
* **Трассировка маршрутов** — построение цепи остановок выбранного направления на карте, расчёт длины трассы и коэффициента непрямолинейности.
* **Дублирование сети (Жаккар)** — выявление пересекающихся маршрутов с настраиваемым порогом совпадения и автоматической генерацией управленческого решения.
* **Симулятор оптимизации** — интерактивный подбор интервала движения и класса вместимости автобуса под целевую загрузку салона 75%, сводная таблица по округу и выгрузка рекомендаций в CSV (`UTF-8-SIG` для Excel).

## Источник данных

| Что | Где |
| :--- | :--- |
| **Первичный источник** | Портал открытых данных Правительства Москвы — [data.mos.ru](https://mos.ru) |
| **Остановочные пункты** | Набор № 752 (координаты WGS84, округа, районы, направления, перечни маршрутов, статус активности) |
| **Вестибюли метрополитена** | Набор № 624 (координаты действующих входов и выходов для расчёта центров станций) |
| **Пассажиропоток метро** | Набор № 62743 (квартальные сведения о количестве входящих и выходящих пассажиров по станциям) |
| **Охват выборки** | 12 административных округов Москвы, более 11 000 активных остановочных пунктов, ~800 маршрутов |

**Ограничения источников:** в открытом доступе отсутствуют данные поостановочных валидаций наземного транспорта, а также точные текущие интервалы движения по каждому рейсу. Поэтому пиковый пассажиропоток остановок восстанавливается расчётным путём по пространственно-гравитационной модели, а параметры выпуска автобусов задаются интерактивно в симуляторе.

## Быстрый старт

```bash
git clone https://github.com<ваш-логин>/<имя-репозитория>.git
cd <имя-репозитория>
pip install -r requirements.txt
streamlit run app.py
```

В репозитории уже находится подготовленный файл `transport_data.csv`, поэтому приложение запускается сразу. Чтобы пересобрать датасет из свежих самостоятельно скаченных JSON-выгрузок `data.mos.ru`:

```bash
python utils/match_metro_coords.py
```

Скрипт `match_metro_coords.py`:
1. автоматически определяет кодировку выгрузок (`utf-8` / `cp1251`) и отбирает только действующие остановки и вестибюли;
2. усредняет координаты выходов для определения географических центров станций метро и переводит квартальный поток в среднесуточный;
3. строит пространственный индекс (`cKDTree`) для поиска ближайшей станции метро к каждой остановке;
4. рассчитывает пиковый часовой пассажиропоток с учётом базового спроса и зоны притяжения ТПУ (радиус 400 м);
5. сохраняет итоговый набор в `transport_data.csv`.

## Методика расчёта

* **Пиковый пассажиропоток остановки** — сумма базового спроса (пропорционально числу проходящих маршрутов) и доли пикового часового потока ближайшей станции метро (12% от суточного потока) для остановок в радиусе 400 м.
* **Коэффициент непрямолинейности** — отношение длины трассы маршрута (сумма геодезических расстояний по формуле гаверсинуса) к расстоянию по прямой между конечными остановками. Значение `> 1.6` сигнализирует о необходимости спрямления.
* **Индекс дублирования (коэффициент Жаккара)** — отношение числа общих остановок пары маршрутов к общему числу их уникальных остановок (`× 100%`). При совпадении `> 75%` рекомендуется объединение маршрутов, ниже — тактовое расписание.
* **Коэффициент наполняемости салона** — отношение часового спроса на маршрут (18% от суммарного потока остановок трассы) к провозной способности (`(60 / интервал) × вместимость автобуса`). Целевой норматив комфорта — `0.75`.
